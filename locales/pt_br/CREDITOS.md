# Tradução pt_BR

Tradução para o português do Brasil feita pela **Comunidade dotProject Brasil**
(dotproject.com.br, coordenada por Diego Viégas), distribuída como pacote de
idioma para o dotProject 2.1.x e mantida aqui sob a mesma licença do projeto
(GNU GPL v2).

O dotProject BR atualiza e completa esta tradução para as versões novas.
